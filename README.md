# SmartHealth 智慧健康資訊網站

## 專案簡介

SmartHealth 是一個以醫療品質資訊及健康衛教為主題的網站，整合不同疾病的基本介紹、醫療品質資訊及健康教育內容，讓民眾能夠透過簡單的網頁操作，快速查找所需的健康資訊。

本網站參考全民健康保險醫療品質資訊公開網的資訊呈現方式，以疾病分類作為主要導覽架構。目前提供「糖尿病」及「氣喘」兩種疾病資訊，未來可持續新增其他疾病主題。

## 專案目的

- 整合疾病介紹、醫療品質資訊及健康衛教內容。
- 提供清楚的疾病分類與網頁導覽。
- 讓民眾更方便地查找健康資訊。
- 建立可重複使用的網頁架構，方便未來擴充其他疾病頁面。

## 網站功能

### 1. 首頁
- 顯示網站名稱與簡介。
- 提供疾病分類及各疾病頁面的入口。
- 提供網站資訊閱讀提醒。

### 2. 疾病介紹
- 提供疾病基本介紹。
- 協助使用者認識疾病相關資訊。

### 3. 醫療品質資訊
- 規劃疾病相關醫療品質指標資訊。
- 說明醫療品質指標的用途。
- 正式指標資料以公開且可信任的來源為準。

### 4. 健康教育
- 提供疾病相關健康知識。
- 整理日常照護及生活注意事項。
- 提供就醫與定期追蹤提醒。

## 目前提供的疾病主題

| 疾病名稱 | 網頁檔案 | 主要內容 |
|---|---|---|
| 糖尿病 | `docs/diabetes.html` | 疾病介紹、醫療品質資訊、健康教育、照護提醒 |
| 氣喘 | `docs/asthma.html` | 疾病介紹、醫療品質資訊、健康教育、照護提醒 |

## 未來擴充方向

未來預計新增更多常見疾病主題，例如：

- 高血壓
- 慢性腎臟病
- 慢性阻塞性肺病
- 其他常見慢性疾病


## 資料來源與使用限制

本網站參考全民健康保險醫療品質資訊公開網的疾病分類及資訊呈現方式。

醫療品質指標應以正式公開資料為依據，健康衛教內容應確認資料來源及正確性。網站僅提供一般健康資訊與衛教參考，不能取代醫師診斷、治療或個別醫療建議。
